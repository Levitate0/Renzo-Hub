# Renzo — `demo` build (store-listing screenshots)

A build variant of the normal Android app whose **only** difference is that
every image fetched from the server is replaced by the Renzo app icon on a flat
plate.

Everything else is real: your real server, your real login, your real library,
real playback. So the screenshots show the actual product — just with no
publisher artwork in them.

**What gets replaced**

| Where | Replaced with |
|---|---|
| Poster cards (Discover, Library, Updates, History, Search) | `poster.png` (2:3) |
| Season / franchise strip on a series page | `poster.png` |
| Detail-page hero banner | `banner.jpg` (16:9) |
| Episode thumbnails | `thumb.jpg` |
| Scrub-bar preview frames | `preview.jpg` |
| The video surface while playing | `video-cover.jpg` |

A decoded video frame is copyrighted content too, so the player's picture is
covered while playback keeps running underneath — the controls, timeline,
subtitles and episode chrome are all live and photographable.

The plates are generated by [`tools/gen-demo-placeholders.sh`](tools/gen-demo-placeholders.sh)
into `app/src/demo/assets/placeholder/`. Re-run it if the icon ever changes.

> **Never publish this variant.** It installs as
> `top.levitatemedia.renzo.demo`, so it sits alongside the real app instead of
> replacing it, and it is debug-signed. Upload builds still come from
> `release`.

## Build it in Android Studio

1. Open `/opt/zurg-stack/renzo-clients/tv-native` (the `tv-native` folder) and
   let Gradle sync.
2. **View → Tool Windows → Build Variants** (or the *Build Variants* tab in the
   left gutter).
3. Set the `:app` module's **Active Build Variant** to `demo`.
4. Run on your emulator as normal. No keystore needed — `demo` is debug-signed.

Switch the same dropdown back to `release` for a real build.

Command line equivalent:

```
./gradlew :app:assembleDemo      # app/build/outputs/apk/demo/app-demo.apk
```

## Point it at your server

The demo build has no server baked in — it shows the same Connect screen as the
real app.

- Renzo on another machine on your LAN: use its normal address.
- Renzo on the **same Windows box** as the emulator: use `http://10.0.2.2:<port>`.
  `10.0.2.2` is how the Android emulator reaches the host's loopback;
  `localhost` inside the emulator is the emulator itself.

Plain `http://` is fine — the app allows cleartext for self-hosted servers.

## Emulator profiles for the four Play form factors

| Form factor | Resolution | Density | Orientation |
|---|---|---|---|
| Phone | 1080 × 1920 | 420 dpi | portrait |
| 7" tablet | 1200 × 1920 | 320 dpi | portrait |
| 10" tablet | 1920 × 1200 | 240 dpi | landscape |
| Android TV | 1920 × 1080 | 320 dpi | landscape, launch with `-e tv 1` |

Either create four AVDs in **Device Manager → Create Device** (any Pixel-class
device, API 34 x86_64 image, 4 GB RAM), or keep one emulator and resize it:

```
adb shell wm size 1920x1200 && adb shell wm density 240
...capture...
adb shell wm size reset && adb shell wm density reset
```

`-e tv 1` forces the leanback layout, locks landscape and hides the status and
navigation bars — so TV screenshots can be shot from an ordinary phone AVD
without installing a separate Android TV system image.

## Jumping straight to a page

Driving the UI by hand for every page × every form factor is miserable, so the
demo build takes launch extras:

| Extra | Values |
|---|---|
| `-e page` | `discover` `category` `library` `library-folder` `updates` `history` `downloads` `search` `title` `player` `account` `credentials` `defaults` `apikey` `users` `settings` `appearance` `drawer` `accountmenu` |
| `-e tv` | `1` — TV layout, landscape, no system bars |
| `-e theme` | a preset id (`renzo`, `midnight`, … — see `ui/theme/Presets.kt`) |
| `-e query` | search text, for `-e page search` |
| `-e id` | AniList id, required by `-e page title` and `-e page player` |
| `-e ep` | episode number for `-e page player` (default 1) |
| `-e section` | pane for `-e page account`, or the folder name for `library-folder` |

In Android Studio: **Run → Edit Configurations → Launch Flags**, e.g.

```
-e page library
```

Or over adb:

```
adb shell am start -S -n top.levitatemedia.renzo.demo/top.levitatemedia.renzo.tv.MainActivity -e page updates
adb shell am start -S -n top.levitatemedia.renzo.demo/top.levitatemedia.renzo.tv.MainActivity -e page title -e id 21
adb shell am start -S -n top.levitatemedia.renzo.demo/top.levitatemedia.renzo.tv.MainActivity -e page discover -e tv 1
```

`title` and `player` need an id from **your** library — grab one from the URL
bar of the web UI, or just navigate there by hand.

## Taking the screenshots

- The camera button in the emulator's side toolbar saves a PNG at the
  emulator's exact resolution (Android Studio's default is your Desktop).
- Or run [`tools/capture-play-shots.ps1`](tools/capture-play-shots.ps1) from
  PowerShell to sweep every form factor × page automatically.

### What Google Play wants

| Asset | Requirement | Where |
|---|---|---|
| Phone screenshots | 2–8, 1080 × 1920 | capture |
| 7" tablet | up to 8 | capture |
| 10" tablet | up to 8, landscape | capture |
| Android TV | up to 8, 1920 × 1080 landscape | capture with `-e tv 1` |
| TV banner | 1280 × 720 | needs making |
| Feature graphic | 1024 × 500 | `renzo-clients/artifacts/feature-graphic-1024x500.png` |

## Troubleshooting

**Real cover art is still showing.** You're running the wrong variant — check
the Build Variants panel says `demo`, and that the app on the emulator is
`top.levitatemedia.renzo.demo` (the demo and real apps can both be installed).

**Screenshots are black.** The emulator's GPU mode; try *Cold Boot Now* from
Device Manager, or switch the AVD's graphics setting to *Software*.

**Can't reach the server.** From the emulator, the host is `10.0.2.2`, not
`localhost`. Check the port is bound on the host and not firewalled.

**Emulator is stuck at a weird resolution** after a capture run:

```
adb shell wm size reset && adb shell wm density reset
```

**Player shows the plate but no controls.** Tap once — the controls auto-hide,
same as the real app.
